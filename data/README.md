# Datos

Los CSV del dataset MIT-BIH no se incluyen en el ZIP compacto de entrega porque el
campus limita la subida a 50 MB.

Para ejecutar el entrenamiento completo, coloca en esta carpeta los ficheros:

- `mitbih_train.csv`
- `mitbih_test.csv`

En el entorno local usado para preparar el proyecto estos ficheros estaban presentes y
el codigo espera exactamente esos nombres y rutas.
